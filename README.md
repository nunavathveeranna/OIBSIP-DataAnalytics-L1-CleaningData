# Retail Sales Data Cleaning

## Overview
This project focuses on cleaning and preprocessing a retail sales dataset using Python, Pandas, and NumPy.

## Tasks Performed
- Inspected dataset structure, data types, and missing values.
- Handled missing values using appropriate imputation strategies.
- Identified and removed duplicate records.
- Standardized text values and corrected data types.
- Detected potential outliers using the IQR method.
- Compared data quality before and after cleaning.
- Exported the cleaned dataset to a new CSV file.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- KaggleHub

## Dataset
[Retail Store Sales — Dirty for Data Cleaning](https://www.kaggle.com/datasets/ahmedmohamed2003/retail-store-sales-dirty-for-data-cleaning)

## Output
`retail_store_sales_cleaned.csv`

## Objective
To improve data quality and prepare a reliable dataset for further analysis.
